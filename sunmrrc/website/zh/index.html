核心功能

完整的 SDR 服务器

从 UDP IQ 流到浏览器 FFT 瀑布图——每一层均已逆向工程并重建。

IQ 解调

服务端 IQ 解调，基于 numpy/scipy。DDC + 分数重采样器 + 重叠保留法 Hilbert SSB 调制器。WFM 高保真模式含立方重采样。

  • numpy/scipy DSP 管线
  • Hilbert SSB 调制器
  • 48kHz RX 音频管线

512-bin FFT 瀑布图

基于 IQ 采样的实时频谱。512-bin FFT 含动态频率标尺（39k/78k/156k/312k IQ 带宽）。精确采样率查找，像素对齐。

  • 39k-312k IQ 带宽选项
  • xScale = W/n 像素对齐
  • 多客户端状态同步

双编解码音频

标签双编解码传输：Opus 64kbps + Int16 PCM 回退。WDSP NR2/ANF/SNB 在 IQ 级处理（解调前）。完整 WDSP 设置面板含持久化。

  • Opus/PCM 标签二进制传输
  • WDSP IQ 级处理
  • NR2/AGC/NB/ANF 面板 + 持久化

5 路 WebSocket

/WSCTRX（双向 cmd:val）、/WSaudioRX（标签 Opus/PCM）、/WSaudioTX（麦克风上行）、/WSspectrum（512-bin 二进制）、/WSATR1000（天调）。协议即契约——SunsdrMobile 零服务端改动即可运行。

  • cmd:val JSON 协议
  • 标签双编解码音频传输
  • 稳定契约 → SunsdrMobile 单次提交 V1.0

逆向工程协议

100% 未知协议表面。40+ 次 Wireshark 会话解码 12 种命令类型、30 包启动序列和私有二进制 UDP 协议。PROTOCOL.md 含 22 章节。

  • 12 种解码命令类型
  • PROTOCOL.md（22 章节）
  • 0x0017 DRIVE + 0x1F00 遥测

复用 8 项 MRRC 资产

PTT 安全模型（ACK × 3、看门狗）、WDSP 集成模式、多实例架构、设计令牌、AudioWorklet RX 管线——继承自 MRRC，无需重新解决。

  • PTT ACK × 3 + 看门狗 + 触屏释放
  • WDSP 集成 + 多实例架构
  • COEP credentialless for SharedArrayBuffer

工程环

分工与沉淀契约

本工程环在编辑前加载什么、哪些仍由人签字、事后留下什么可读的东西。

01 · 编辑前加载
加载 CLAUDE.md 与 AGENTS.md，无注册表
本工程带有 AGENTS.md、CLAUDE.md 与 SDD/ 源树，编辑前均会被读取。没有机器可读约束注册表，因此不声称存在自动编辑前门禁。
02 · 人来签字
逆向协议与 PTT
对 SunSDR2 协议的任何推断，以及在非自家硬件上的任何 PTT 闭合，都由人签字。猜测一律标注为猜测。
03 · 沉淀的契约
PROTOCOL.md 与 SDD 章节
PROTOCOL.md 与 SDD 章节作为对链路可持续复审的描述留存在此。
